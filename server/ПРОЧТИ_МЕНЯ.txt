RAILWAY / TextDraw

1. Change rcon_password in server.cfg.
2. Start samp-server.exe from this folder.
3. Connect with a standard SA-MP 0.3.7 client.

No browser runtime or plugins are required. Keep scriptfiles/railway.db!
Y = vehicle menu, N = engine, H = doors. /settings = native control settings.
/vmenu /engine /door /key are also available.
Password entry: click LOGIN / REGISTER, then enter a password in the masked dialog.
