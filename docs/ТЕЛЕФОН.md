# Телефон

Телефон — предмет в инвентаре. Сим-карта даёт ему номер, баланс и тариф.
Интерфейс — браузерная страница (omp-cef), но **вся логика на сервере**:
игрок без клиентской части плагина звонит и пишет теми же командами чата.

## Предметы

| Предмет | Тип | Что делает |
|---|---|---|
| `phone` (Телефон) | `ITEM_PHONE` 9 | лежит в инвентаре, открывается кнопкой `OPEN` или `/phone` |
| `sim_card` (Сим-карта) | `ITEM_SIM` 8 | расходуется командой `/sim`, даёт шестизначный номер |

Выдача администратором:

```
/giveitem <id> phone 0     — PHONE BRICK (модели 0/1/2)
/giveitem <id> sim 1       — сим-карта с тарифом Active
```

Вес: телефон 0,3 кг, сим-карта 0,01 кг.

## Номер и тариф

- `/sim` — вставить сим-карту: предмет исчезает из инвентаря, аккаунту
  выдаётся свободный номер от `100000` до `999999`.
- `/tariff <0-2>` — `Start`, `Active`, `Maxi`.
- `/topup <amount>` — пополнить с наличных (до 10 000 за раз).

| Тариф | Минута разговора | SMS |
|---|---|---|
| Start | 1 | 3 |
| Active | 2 | 2 |
| Maxi | 5 | 1 |

Минута списывается в момент соединения и дальше раз в минуту; платит
набравший номер. Если денег на счету нет, звонок сбрасывается.
Остаток хранится в БД и не пропадает между заходами.

## Звонки и SMS

| Действие | Браузер | Команда |
|---|---|---|
| Позвонить | приложение «Phone» | `/call <номер>` |
| Ответить | зелёная кнопка | `/pickup` |
| Сбросить | красная кнопка | `/hangup` |
| Написать | приложение «Messages» | `/sms <номер> <текст>` |
| Контакты | приложение «Phone» → контакты | `/contacts`, `/addcontact <имя> <номер>` |
| 911 | приложение «Phone» → 911 | `/911 <причина 0-5>` |

Во время разговора **обычный чат превращается в телефонный**: реплика уходит
собеседнику, а стоящие рядом (8 м) слышат только вашу половину фразы.
Сообщения до 96 символов, история последних 12 штук показывается в приложении
 Messages и хранится в БД.

Гудки длятся 20 секунд: не ответили — «No answer». Режим «Не беспокоить»
(в настройках) отключает входящие звонки и SMS.

## Y-меню

Клавиша `Y` (по умолчанию) разбирает контекст по порядку:

1. **Машина под прицелом** (до 6 м) — карточка автомобиля, как раньше.
2. **Игрок рядом** (до 3,5 м) — если его номер у вас в контактах, сразу
   звонок; если нет — обмен номерами (он тоже получит ваш).
3. **Иначе — вы сами**: открывается телефон (`/phone`).

Привязка клавиш меняется в `/settings`.

## 911

Причины: `0` Robbery, `1` Shooting, `2` Hostages, `3` Injured, `4` Fire,
`5` Other. Вызов уходит всем, кто в сети, и ставит красную метку на карте.
Отдельных фракций (полиция, EMS) в этом моде пока нет — когда появятся,
вызов будет уходить в нужную.

## Приложения

В телефоне 12 приложений. Работают: **Phone** (звонки, контакты, 911),
**Messages**, **Operator** (номер, баланс, тариф, пополнение),
**Settings** (обои, рингтон, «не беспокоить») и **Lawyers**
(список адвокатов с рейтингом и ценой — только из КПЗ, см. docs/ПОЛИЦИЯ.md;
вне камеры приложение отвечает, что вызывать адвоката можно только оттуда).

Остальные семь написаны и работают. Открываются из сетки приложений
(браузер) или командой `/apps` (текстовое меню), у каждого приложения свой
экран со строками и свои команды чата:

| Приложение | Что делает | Команды |
|---|---|---|
| **Bank** | баланс наличных и счёта, оплата штрафов, вход в терминал у банкомата, перевод, зарплата | `/payfines`, `/bank`, `/transfer <id> <сумма>`, `/payday` |
| **Weather** | прогноз по всему серверу и бонус к оплате заданий | `/weather` |
| **Group** | группа: чат, метка лидера на карте, приглашения | `/group`, `/ginvite <id>`, `/gaccept`, `/gleave`, `/g <текст>` |
| **Lawyers** | вызов адвоката **только из камеры**, список дежурных, лицензия, раздел залога | `/lawcall`, `/lawprice` |
| **Uber Drive** | заказ такси, приём заказа водителем на Cabbie/Taxi, расчёт при высадке | `/taxi`, `/uber` |
| **Weazel News** | доска объявлений: просмотр и подача за 100 | `/news`, `/ad <текст>` |
| **Auto Plus** | список личных машин и доставка к владельцу за 200 | `/auto`, `/deliver <id>` |
| **Camera** | снимок как предмет: ориентир и время, можно показать рядом | `/snap`, `/photo` |

Подробности каждого приложения — в [docs/ПРИЛОЖЕНИЯ_ТЕЛЕФОНА.md](ПРИЛОЖЕНИЯ_ТЕЛЕФОНА.md).

## База данных

```sql
CREATE TABLE IF NOT EXISTS phone_apps (player_id INT, app_id VARCHAR(32), installed BOOLEAN);
CREATE TABLE IF NOT EXISTS phone_settings (player_id INT, wallpaper VARCHAR(64), ringtone VARCHAR(64), dnd BOOLEAN);
CREATE TABLE IF NOT EXISTS sim_cards (player_id INT, sim_number VARCHAR(16), tariff VARCHAR(32), balance INT);
CREATE TABLE IF NOT EXISTS phone_contacts (player_id INT, name VARCHAR(32), sim_number VARCHAR(16));
CREATE TABLE IF NOT EXISTS phone_sms (id INTEGER PRIMARY KEY AUTOINCREMENT, from_num VARCHAR(16), to_num VARCHAR(16), body TEXT, stamp INT);
```

`player_id` — это `accounts.id`. Первые три таблицы — из вашего описания,
контакты и сообщения добавлены к ним.

## Где что лежит

| Файл | Роль |
|---|---|
| `server/pawno/include/railway/phone.inc` | вся логика: сим-карты, звонки, SMS, контакты, 911, команды |
| `server/pawno/include/railway/cefui.inc` | браузер 102 (слой 150), события `phone:*` |
| `server/scriptfiles/cef/railway/phone.html` | страница телефона |
| `server/scriptfiles/cef/railway/js/phone.js` | сетка приложений, экраны, звонок |
| `server/scriptfiles/cef/railway/css/phone.css` | корпус, обои, плитки, кнопки |

Страницу можно открыть и править без игры — отдайте каталог любым
веб-сервером или откройте `phone.html` в браузере: без плагина она
показывает демо-телефон с тестовыми контактами.

Тесты: `tests/phone_test.py` — схема и SQL исполняются на реальной SQLite,
плюс проверки тарифов, Y-меню, команд и совпадения событий сервера и страницы.
