# Как это устроено

## Стек

```
Kлиент: GTA SA 1.0 + SA-MP 0.3.7 R5-2 + cef.asi (+ папка cef\)
                        │                 │
                игровой UDP 7777     CEF-канал UDP 7779 (порт + 2)
                        │                 │
Сервер: samp-server.exe 0.3.7-R2-2-1 + plugins\cef.dll
                        │
                gamemodes\railway.amx (Pawn)
                        │
        scriptfiles\cef\railway_auth\  ·  scriptfiles\cef\railway_speedo\
                (HTML/CSS/JS отдаются клиенту сервером)
```

* **CEF-плагин:** `aurora-mp/omp-cef` v1.4.0 (CEF 148), серверная часть —
  `plugins\cef.dll` для SA-MP, клиентская — `cef.asi` + рантайм в `cef\`.
* **Ресурсы UI** лежат в `scriptfiles\cef\<resource>\` и регистрируются в Pawn
  через `CEF_AddResource`. Клиент запрашивает их как
  `http://cef/<resource>/index.html`; интернет не используется.
* **База:** SQLite, встроенная в `samp-server.exe` (нативы `db_open`, `db_query`
  из `a_sampdb.inc`). Файл — `scriptfiles\railway.db`.

## Модули гейммода

```
server\gamemodes\railway.pwn        только колбэки (+ #pragma dynamic)
server\pawno\include\railway\
   core.inc        константы, состояние игроков/машин, утилиты, названия моделей
   ui.inc          все вызовы CEF-нативов (браузеры, слои, события)
   accounts.inc    SQLite, регистрация/вход, камера на экране входа, резервные диалоги
   vehicles.inc    владение, ключ, двери, /spcar, блокировка движения
   speedo.inc      расчёт скорости/передачи и рассылка в CEF
   commands.inc    парсер команд, /help, админ-команды
```

### Поток входа

1. `OnPlayerConnect` → `TogglePlayerSpectating(true)`, камера облетает вокзал
   (таймер 60 мс), запускается таймер резервного входа (3 с).
2. Клиент поднимает CEF → `OnCefReady` → `CEF_AddResource` уже сделан в
   `OnGameModeInit`, создаётся браузер `1001` (полноэкранный, в фокусе).
3. Страница грузится и сама сообщает `auth:ready` → сервер отдаёт `auth:init`
   (ник, есть ли аккаунт, версия). Так исключается гонка «событие пришло раньше
   загрузки страницы».
4. Ввод пароля → `auth:login` / `auth:register` → сервер валидирует, работает
   с SQLite, отвечает `auth:result` (код результата, не текст — тексты живут в JS,
   чтобы не тащить русский через кодировки Pawn → CEF).
5. Успех → `auth:hide`, игрок спавнится на перроне, камера снимается.

Резервный путь: если CEF не поднялся (ошибка инициализации, браузер не создан или 3 с без событий), сразу показываются обычные диалоги
SA-MP (`DIALOG_STYLE_PASSWORD`) — сервер остаётся играбельным даже без
клиентских файлов CEF.

### Поток машины

```
/spcar <id>
  ├─ проверка модели (400–611, без поездов и прицепов)
  ├─ CreateVehicle в 4.4 м перед игроком, цвет из палитры, номер RW-XXX
  ├─ слот в пуле (100 машин), владелец = id аккаунта + ник
  └─ закрытые двери и «ключ не вставлен» → двери заперты для всех
```

| Команда | Что меняется |
|---|---|
| `/door` | `vsDoors` → `SetVehicleParamsCarDoors` + снятие/постановка замка |
| `/key` | `vsKey` → двигатель, при вставке двери закрываются |
| посадка за руль | `OnPlayerStateChange` → `RW_Veh_OnEnterDriver` |
| каждый тик (0.4 с) | `RW_Veh_Enforce`: владелец + ключ = едем, иначе глушим |

Право на движение:

```pawn
RW_Veh_CanDrive(playerid, vehicleid) =
       gVeh[slot][vsUsed]
    && gLogged[playerid]
    && gVeh[slot][vsOwnerAcc] == gAccountId[playerid]
    && gVeh[slot][vsKey];
```

Запрет реализован на сервере: `SetVehicleParamsEx(engine = 0)` + обнуление
вектора скорости, поэтому «прошить» его клиентом нельзя. Игрок не блокируется
целиком — он может спокойно выйти из машины.

### Спидометр

`RW_SpeedoTick` (150 мс) для каждого игрока за рулём:

1. `GetVehicleVelocity` → `км/ч = длина вектора * 180`;
2. проекция скорости на ось машины → определяем задний ход (`R`);
3. передача по полосам `0–26 / 26–52 / 52–84 / 84–120 / 120–162 / 162+` км/ч
   с гистерезисом (не «дребезжит» на границе);
4. обороты — доля внутри полосы (1000…6200);
5. `CEF_EmitEvent(..., "speedo:update", speed, gear, rpm, flags)`.

`flags`: `1` двигатель, `2` ключ, `4` двери, `8` владелец, `16` ехать нельзя.
Клиент интерполирует значения в `requestAnimationFrame`, поэтому стрелка и цифры
плавные даже при 6–7 пакетах в секунду.

## События CEF

| Направление | Событие | Аргументы |
|---|---|---|
| JS → Pawn | `auth:ready` | — |
| JS → Pawn | `auth:login` | пароль |
| JS → Pawn | `auth:register` | пароль, повтор |
| JS → Pawn | `speedo:ready` | — |
| Pawn → JS | `auth:init` | ник, есть аккаунт, версия |
| Pawn → JS | `auth:result` | ok, код (ник опционален: JS берёт его из `auth:init`) |
| Pawn → JS | `auth:busy` | занято |
| Pawn → JS | `auth:hide` | — |
| Pawn → JS | `speedo:show` | модель-имя, modelid, владелец |
| Pawn → JS | `speedo:update` | скорость, передача, обороты, флаги |
| Pawn → JS | `speedo:hide` | — |

Коды результата входа: `ok:login`, `ok:register`, `err:short`, `err:long`,
`err:mismatch`, `err:exists`, `err:noaccount`, `err:inuse`, `err:chars`,
`err:nick`, `err:db`, `err:cooldown`, `err:badpass:<осталось попыток>`.
Тексты — в `railway_auth\app.js` (объект `MESSAGES`), их легко править
без пересборки гейммода.

## Безопасность

* Пароли: `SHA256_PassHash(пароль, соль)`, соль 32 hex-символа на аккаунт,
  `SHA256_PassHash` — серверная реализация, открытый пароль не сохраняется и не
  логируется.
* Ник валидируется (`A–Z a–z 0–9 _ $ = ( ) [ ] { } . @`, 3–20 символов),
  строки перед SQL дополнительно проверяются на кавычки/обратные слэши.
* 5 неверных паролей — кик; между попытками 400 мс; аккаунт нельзя занять дважды.
* Все события из JS считаются недоверенным вводом: сервер проверяет состояние
  игрока, расстояние до машины, владение и кулдауны.
* `cef_master_resource_key` в `server.cfg` — свой 16-символьный ключ вместо
  дефолтного.

## Кодировки (важно при правках)

| Файлы | Кодировка | Почему |
|---|---|---|
| `*.pwn`, `*.inc` | Windows-1251 | так русский текст корректно рисуется в чате/диалогах SA-MP |
| `server.cfg` | Windows-1251 | хостнейм с кириллицей |
| `scriptfiles\cef\**` (HTML/CSS/JS) | UTF-8 | стандарт для Chromium (CEF 148) |
| `*.ps1`, `*.md` | UTF-8 | PowerShell 5.1 читает UTF-8 с BOM, редакторы — без проблем |

Из-за разницы кодировок тексты для CEF-интерфейса передаются **кодами**
(`err:short`), а расшифровываются в JS — так кириллица не «ломается» на границе
Pawn (1251) → CEF (UTF-8).

## Совместимость AMX

`pawncc` 3.10+ с оптимизатором `-O2` включает «макро-опкоды» и пишет AMX версии 9,
который сервер SA-MP 0.3.7 (AMX версии 8) не загружает. Приложенный
`railway.amx` собран с `-O0`: заголовок `file_version = 8`, `amx_version = 8`,
то есть совместим с 0.3.7. `server\pawno\pawncc.exe` (3.2.3664 из пакета SA-MP)
пишет версию 8 всегда.
