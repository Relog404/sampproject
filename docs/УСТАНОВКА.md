# Установка сервера и клиента

Инструкция для Windows. Всё, что нужно, лежит в репозитории; из интернета
скачиваются только официальные бинарники CEF (скрипт делает это сам).

---

## 0. Что понадобится

| Компонент | Где взять |
|---|---|
| GTA San Andreas 1.0 US | своя установка |
| Клиент SA-MP **0.3.7 R5-2** | `https://www.sa-mp.mp/downloads` |
| ASI loader (`dinput8.dll`) | Silent's ASI Loader (любой популярный пакет) |
| CEF v1.4.0 (сервер + клиент) | скачает `setup.ps1` |

Проверьте, что игра запускается и SA-MP подключается к любому серверу **до**
установки CEF — так проще понять, что именно сломалось, если что-то пойдёт не так.

---

## 1. Клиент SA-MP

1. Установите SA-MP 0.3.7 R5-2 в папку с GTA San Andreas.
2. Убедитесь, что `gta_sa.exe` и `samp.dll` лежат в одной папке.

Проверка билда (необязательно, но полезно):

```powershell
powershell -ExecutionPolicy Bypass -File .\client\check-samp-build.ps1
```

Скрипт покажет PE-подпись `samp.dll`, версию файла и вердикт: распознает ли
CEF-плагин этот билд.

---

## 2. CEF: сервер и клиент

Откройте PowerShell **в папке проекта**:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -GtaPath "C:\Program Files (x86)\Rockstar Games\GTA San Andreas"
```

Что произойдёт:

1. Скачается `cef-samp-v1.4.0.zip` (1 113 197 байт) →
   SHA-256 `7bc5d05b…c8d28` — проверяется автоматически.
2. Из архива распакуются:
   * `server\plugins\cef.dll`
   * `server\pawno\include\cef.inc`
3. Скачается `client-files-v1.4.0.zip` (~146 МБ) →
   SHA-256 `9bdcf634…4e55f` — тоже проверяется.
4. В папку игры распакуются `cef.asi` и папка `cef\`
   (`client.dll`, `renderer.exe`, `libcef.dll`, `locales`, `resources`…).
5. Скрипт проверит наличие `cef.asi`, `cef\client.dll`, `gta_sa.exe`, `samp.dll`
   и ASI loader, о проблемах напишет прямым текстом.

Полезные варианты:

```powershell
.\setup.ps1 -ServerOnly                 # только серверный плагин
.\setup.ps1                             # сервер; клиент — в client\gta-files
.\client\install-client.ps1 -GtaPath "D:\Games\GTA SA"
.\client\install-client.ps1 -DownloadOnly
.\setup.ps1 -Force                      # перекачать архивы заново
```

Архивы кэшируются в `.cache\` — повторный запуск не качает их снова.

### Шаг 2 выполнен, а сервер пишет «Failed.»

Если в `server_log.txt` видно

```
Loading plugin: cef
 Failed.
Loaded 0 plugins
Script[gamemodes/railway.amx]: Run time error 19: "File or function is not found"
```

— значит `cef.dll` нет или Windows не смогла его загрузить. `Run time error 19`
здесь только следствие: нативы `CEF_*` не зарегистрированы, потому что плагин
не поднялся.

Запустите диагностику:

```
server\tools\check-plugin.cmd
```

Скрипт скажет, чего не хватает (файл, разрядность, экспорты, `server.cfg`,
код ошибки Windows при загрузке DLL) и что именно делать. Частые причины:

| Что видно | Причина | Решение |
|---|---|---|
| файла нет | `setup.ps1` не запускался или не смог скачать архив | `setup.ps1 -ServerOnly`, при отсутствии интернета — вручную (см. `server\plugins\README.txt`) |
| код 193 | в `plugins\` положили 64-битный `client.dll`/`cef.asi` | нужен `cef.dll` из `cef-samp-v1.4.0.zip` |
| код 14001 | нет Visual C++ Redistributable | поставить «VC++ 2015-2022 (x86)» |
| `Loaded 0 plugins`, но ошибки загрузки нет | в `server.cfg` нет строки `plugins cef` | добавить строку `plugins cef` (без `.dll`) |
| плагин загружается, но браузеры не открываются | редко — несовместимость серверного бинарника | попробовать `samp-server.exe` 0.3.7-R5-1/R5-2 |

### Если ASI loader не найден

`cef.asi` — это ASI-плагин, он загружается загрузчиком (`dinput8.dll`,
`vorbisFile.dll` и т. п.). Положите `dinput8.dll` в корень игры и запустите
`client\check-samp-build.ps1` ещё раз — там будет строка `ASI loader: ...`.

## 3. Настройка сервера

Откройте `server\server.cfg`:

```ini
rcon_password change_me_now      ; ← обязательно смените
maxplayers 50
port 7777
hostname Железнодорожный вокзал | CEF UI | 0.3.7 R5-2
gamemode0 railway 1
plugins cef

cef_resources_loader_mode cef
cef_debug 0
cef_master_resource_key RailwayVokzal26!
```

* `port 7777` — игровой порт (UDP). CEF-канал всегда `port + 2`, то есть **7779**.
* `cef_master_resource_key` — 16 символов, ключ шифрования ресурсов CEF.
  Его можно сменить; клиент получает ключ при подключении.
* `cef_debug 1` — подробный лог CEF в консоль сервера (для отладки).

**Брандмауэр:** для игры в интернете разрешите входящие UDP **7777** и **7779**.
Для локальной проверки достаточно `127.0.0.1:7777`.

## 4. Запуск

```
server\samp-server.exe
```

Ожидаемый лог:

```
[railway] База данных готова.
[railway] Готово. Вокзал: Los Santos Unity Station.
```

Если видите `Failed (plugins/cef.dll)` — шаг 2 не выполнен или DLL заблокирована
антивирусом. Если видите `Run time error 19` для `railway.amx` — то же самое:
гейммод использует нативы CEF и не грузится без плагина.

---

## 5. Первый вход

1. Запустите клиент SA-MP 0.3.7 R5-2, подключитесь к `127.0.0.1:7777`.
2. Появится CEF-экран: вкладка «Регистрация» (аккаунта ещё нет).
3. Придумайте пароль (минимум 6 символов) → «Создать аккаунт».
4. Карточка плавно закроется — вы на перроне вокзала.

Дальше:

```
/spcar 411     — Infernus рядом с вами
/door          — открыть двери
(сесть за руль)
/key           — вставить ключ, двигатель заведётся, двери закроются
```

Спидометр появится автоматически при посадке за руль.

---

## 6. Проверка «чужих» машин

Нужен второй игрок (или второй клиент). Второй игрок:

* **не может** открыть двери и вставить ключ (`/door`, `/key` — только владелец);
* если владелец оставил двери открытыми — **может сесть**, но при попытке ехать
  двигатель глохнет, скорость обнуляется, в чате объяснение причины;
* если двери закрыты — не сядет вообще.

---

## 7. Обновление / удаление

* Пересобрать гейммод: `server\tools\build-gamemode.ps1`.
* Сбросить аккаунты: остановить сервер, удалить `server\scriptfiles\railway.db`.
* Удалить CEF: убрать строку `plugins cef` из `server.cfg`, удалить
  `server\plugins\cef.dll`, из игры — `cef.asi` и папку `cef\`.
  (Гейммод без CEF не запустится — он рассчитан на CEF-интерфейс.)
