# Команды

## Игроку

| Команда | Что делает |
|---|---|
| `/help` | список команд |
| `/spcar <id>` | создать машину стандартной модели SA-MP (400–611). Владелец — вызвавший |
| `/door` | открыть/закрыть двери **своей** машины (радиус 6 м или изнутри) |
| `/key` | вставить/вынуть ключ; при вставке двигатель заводится, двери закрываются |
| `/mycar` | состояние своей машины: модель, ключ, двери, двигатель |
| `/stats` | аккаунт, деньги, количество машин в системе |
| `/admins` | администраторы онлайн |

### Популярные модели

| ID | Машина | ID | Машина |
|---|---|---|---|
| 411 | Infernus | 560 | Sultan |
| 429 | Banshee | 562 | Elegy |
| 451 | Turismo | 541 | Bullet |
| 415 | Cheetah | 506 | Super GT |
| 477 | ZR-350 | 480 | Comet |
| 507 | Elegant | 426 | Premier |
| 466 | Glendale | 529 | Willard |

Полный список — стандартные ID SA-MP 400–611 (кроме поездов и прицепов).

## Администратору

| Команда | Уровень | Что делает |
|---|---|---|
| `/ahelp` | 1 | список админ-команд |
| `/kick <id> [причина]` | 1 | кик игрока |
| `/setadmin <ник> <0-3>` | 2 | выдать уровень администратора аккаунту |

Через RCON-консоль (или `rcon setadmin <ник> <уровень>`):

```
setadmin Nick_Name 2
```

### Уровни

| Уровень | Права |
|---|---|
| 0 | обычный игрок |
| 1 | `/kick`, `/ahelp` |
| 2 | + `/setadmin` |
| 3 | резерв (например, владелец проекта) |

Машины, созданные админом через `/spcar`, принадлежат **админу**: никто другой
за руль не поедет.

## Конфигурация в коде

`server\pawno\include\railway\core.inc`:

```pawn
#define SPCAR_MIN_ADMIN_LEVEL   (0)   ; 0 — /spcar доступна всем;
                                      ; 1..3 — только админам
#define SPCAR_COOLDOWN_MS       (1200); пауза между /spcar
#define VEHICLE_SLOTS           (100) ; максимум персональных машин
#define KEY_RANGE               (6.0) ; радиус /key и /door
#define SPEEDO_INTERVAL         (150) ; период обновления спидометра, мс
#define ENFORCE_INTERVAL        (400) ; период проверки права на езду, мс
```

После изменения — пересобрать: `server\tools\build-gamemode.ps1`.
