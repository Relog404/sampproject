# Команды

- `/spcar <id>` — создать личную машину (400–611, без поездов/прицепов).
- `/vmenu` — меню машины под центром камеры до 6 м либо текущего ТС.
- `/door` — двери текущей/прицельной машины, нужен её ключ в инвентаре.
- `/key` — вставить/вынуть ключ текущей машины за рулём, нужен её ключ в инвентаре. Вставка не заводит мотор.
- `/engine` — переключить мотор текущей машины, находясь за рулём со вставленным ключом.
- `/tpm` — подтверждение телепорта к сохранённой метке; `/delmark` — удалить её.
- `/uinative` (алиасы `/uiru`, `/tdrus`) — штатные окна SA-MP; все надписи английские.
- `/uitd` (или `/tdlatin`) — компактные TextDraw с английскими подписями.
- `/settings` — настройки нативных игровых действий, сохраняются на сессию.
- `/mycar`, `/stats`, `/admins`, `/help` — информация.
- `/ahelp`, `/kick` — административные команды с проверкой уровня.
- `/inv`, `/inventory` — TextDraw-инвентарь, закрытие также Esc/X.
- `/giveitem <playerid> <itemid> [vehicleid]` — выдача одного предмета, админ 1+.
  ID 1 — рюкзак; ID 2 — ключ существующей машины (vehicleid обязателен).
- `/setadmin` из игры отключён; назначение только через консоль.

По умолчанию: H двери, N мотор, Y меню. Возможные назначения в `/settings`:
Y/N/H/LAlt. Произвольные физические клавиши, например Ъ или обратный слеш,
без клиентского плагина недоступны. `/cefstatus` и `/authcef` удалены.

RCON: `setadmin <ник> <0-3>` и `dbcheck`.

Подробнее: [инвентарь и ключи](ИНВЕНТАРЬ.md).

- `/garage` — открыть TextDraw-гараж, только рядом с будкой у спавна.
- `/givecar <playerid|account_name> <modelid>` — постоянная машина и ключ, админ 1+.
- `/flycar` — серверная имитация полёта, админ за рулём.
- `/speed <0..500>` — лимит скорости в км/ч; 0 — сброс, админ.
- `/usk <0..100>` — ускорение в км/ч за секунду; 0 — сброс, админ.

[Постоянные ключи и управление полётом](GARAGE_AND_ADMIN.md).

- `/setskin <playerid> <skinid>` — изменить и сохранить скин игрока, админ 1+.
  ID скина 0–311, кроме 74. Игрок должен быть в сети, авторизован и заспавнен.
  Пример: `/setskin 5 104`.
