# Браузерный интерфейс (omp-cef)

Основной слой интерфейса. Страницы — обычный HTML/CSS/JS,
сервер только посылает данные; картинки и шрифты лежат на сервере и сами
скачиваются клиентом. Всё работает в стиле iOS: мягкие полупрозрачные карточки,
скруглённые углы, пружинные анимации.

**Игрок без клиентской части плагина ничего не теряет:** он видит те же меню
штатными окнами SA-MP (`ShowPlayerDialog`), которые умеют кириллицу.
Проверка идёт для каждого игрока отдельно — с браузером играет
только тот, у кого плагин ответил.

## Что нужно

| | |
|---|---|
| Сервер | `server/plugins/cef.dll` (Windows) или `cef.so` (Linux) |
| Конфиг | строка `plugins cef` в `server/server.cfg` |
| Инклюд | `server/pawno/include/cef.inc` (из комплекта плагина) |
| Ресурсы | `server/scriptfiles/cef/railway/` — страницы, стили, скрипты |
| Клиент | *по желанию:* клиентская часть omp-cef той же версии (`4.6.1`) — только у тех, кто хочет браузерные карточки |

Если плагин есть, но ни один игрок так и не ответил, в консоли будет только
`[cef] browser interface ready (resource railway).` — сервер и так работает
на штатных диалогах, браузерные карточки просто никому не показываются.

### Сборка без плагина

По умолчанию плагин обязателен для сервера: AMX импортирует его нативы, и без
`cef.dll` gamemode не загрузится. Чтобы собрать комплект вообще без плагина,
в `railway.pwn` поставьте

```pawn
#define RAILWAY_CEF             (0)
```

Тогда подключается `cefstub.inc` — те же точки входа, всегда выключенные.
Получается сервер без браузера: ни одного CEF-натива в сборке, все меню
открываются штатными диалогами SA-MP.

## Как это включилось в коде

| Файл | Роль |
|---|---|
| `server/pawno/include/railway/cefui.inc` | весь мост к плагину: создание браузеров, события, готовность |
| `server/pawno/include/railway/core.inc` | `gCefEnabled`, `gCefReady`, `gCefMode`, `CEF_MODE_*` |
| `server/pawno/include/railway/ui.inc` | `RW_UI_Panel` пробует CEF, иначе показывает нативный диалог |
| `server/pawno/include/railway/interaction.inc` | карточка машины и список пассажиров в браузере |
| `server/gamemodes/railway.pwn` | `RW_CefInit()` в `OnGameModeInit`, `RW_CefReset(playerid)` на входе/выходе |

Готовность опрашивается, а не ждётся: раз в секунду `RW_CefPulse` спрашивает
`CEF_PlayerHasPlugin(p)` и создаёт браузеры тем, у кого плагин есть.
Колбэки `OnCefReady` / `OnCefInitialize` тоже обрабатываются — сработает то,
что придёт первым. Это сделано потому, что в SA-MP-сборках плагина колбэки
могут не дойти до Pawn.

Браузеры:

* `100` (`CEF_UI_MENU`) — карточка, слой 100, по умолчанию скрыта;
* `101` (`CEF_UI_NOTIFY`) — тосты, слой 200, то есть всегда поверх карточки.

## Протокол

Сервер → страница:

| Событие | Аргументы |
|---|---|
| `ui:open` | `title`, `subtitle` |
| `ui:row` | `id`, `label`, `value`, `icon`, `note`, `valueClass` |
| `ui:action` | `id`, `label`, `style` |
| `ui:end` | — (карточка собрана, показать) |
| `ui:close` | — |
| `ui:toast` | `text`, `kind` (`0` обычный, `1` успех, `2` ошибка) |

Страница → сервер:

| Событие | Аргументы |
|---|---|
| `ui:click` | `id` |
| `ui:closed` | — (игрок закрыл карточку) |

На стороне JS есть тонкая обёртка `RW` (`js/bridge.js`) над `window.cef`,
и `RW.fake(...)` — чтобы открыть страницу прямо в браузере и посмотреть её без
игры. У каждой панели свой адрес:

| Адрес | Что показывает |
|---|---|
| `index.html?fake=1` (или `?fake=car`) | карточка машины |
| `index.html?fake=impound` | штрафстоянка: строки с машинами и выкупом |
| `index.html?fake=market` | витрина маркетплейса и строка действия под ней |
| `index.html?fake=bank` | счёт, нал, переводы стоящим рядом |
| `index.html?fake=property` | дом: покупка, двери, налог, касса |
| `index.html?fake=inv` | инвентарь |
| `index.html?fake=ask` | карточка ввода |
| `phone.html?fake=1` | телефон |
| `hud.html?fake=1` | HUD |

Демо включается **только** адресом: в игре лист остаётся пустым, пока сервер
не пришлёт свою порцию строк, — иначе поверх живого интерфейса на секунду
встал бы чужой.

## Что уже переведено на браузер

* **Карточка машины** (`/car`, либо по кнопке у машины): двери, двигатель,
  ключ, фары, пассажиры, посадка/выход из кабины самолёта, обновить, закрыть.
* **Список пассажиров** того же меню, с выбросом конкретного игрока.
* **Уведомления**: `RW_Info` / `RW_Ok` / `RW_Error` уходят тостами
  (серый / зелёный / красный), максимум 4 штуки, живут 3,2 секунды.

Действия в карточке ровно те же, что в нативном меню: вызывается
`RW_ControlExecute(playerid, vehicleid, действие, цель)` — 0 двери, 1 двигатель,
2 ключ, 3 фары, 4 выброс пассажира. Правила (ключ, дистанция, владелец) те же.

## Закрытие панели

Панель закрывается тремя способами, и все три доходят до сервера:

* кнопка **Close** (`id 8` — страница прячет лист сама и шлёт `ui:closed`);
* **Esc**;
* клик по затемнению вокруг листа.

На сервере это `public RW_CefClosed`: он снимает фокус и курсор мыши, гасит
браузер и сбрасывает режим панели (`RW_UI_Close`), чтобы следующая панель не
решила, что занято. Исключение одно — экран раненого: он возвращается сам,
пока идёт кровотечение. Поле ввода закрывается раньше всех (`RW_InputCancel`),
иначе «ждём ввод» остался бы навсегда.

## Как добавить новый экран

1. В `cefui.inc` добавить `#define CEF_MODE_…` (в `core.inc`) и ветку в
   `RW_CefClick`.
2. Написать `stock RW_CefИмя(playerid)`: `RW_CefOpen` → `RW_CefRow` /
   `RW_CefAction` → `RW_CefEnd`.
3. Написать `RW_CefИмяClick(playerid, id)` и вызвать его из `RW_CefClick`.
4. В точке входа сделать `if (RW_CefOn(playerid)) return RW_CefИмя(playerid);`
   — как уже сделано в `RW_UI_Vehicle`.
5. Иконку добавить в `ICONS` в `js/ui.js` (строковый SVG, цвет из CSS).

Страницы правятся без пересборки gamemode: это файлы в
`scriptfiles/cef/railway/`, их при изменении достаточно перезапустить сервер
(клиент скачивает ресурсы заново).

## Проверки

`python3 -m unittest discover -s tests -p '*_test.py'` — в том числе
`tests/cef_ui_test.py`: плагин подключён, все используемые нативы объявлены,
ресурсы указывают на существующие файлы, события сервера и страниц совпадают,
а каждый вызов плагина защищён проверкой `RW_CefOn`.

Проверяется и то, что сборка с `RAILWAY_CEF 0` вообще возможна
(`cefstub.inc` даёт те же точки входа).

Игровой тест на Windows с живым клиентом эти проверки не заменяют.
