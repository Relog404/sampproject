# Бронежилет

Броня — **отдельный предмет инвентаря** (тип 7). Пока она надета, жилет
отрисовывается на игроке и гасит часть урона. Реализация:
`server/pawno/include/railway/armour.inc`.

**Текстуры лежат только у клиента** — в папке игры `arm/`, сервер не хранит и
не отправляет файлы, а только называет TXD и текстуру:
[клиентские текстуры](КЛИЕНТСКИЕ_ТЕКСТУРЫ.md).

## Как надеть

1. Получить предмет: `/giveitem <id> armour [0-2]` (админ 1+).
   `0` — обычный (100 очков, 65%), `1` — лёгкий (50 очков, 50%),
   `2` — тяжёлый (150 очков, 80%). По умолчанию — `0`.
2. Открыть `/inv`, выбрать броник в MAIN, нажать **WEAR**.
   Предмет уходит из сетки в слот брони (ячейка CHARACTER, третья сверху —
   рядом с рюкзаком и активным оружием).
3. Снять: выбрать надетую броню (клик по ячейке брони или по слоту) и нажать
   **TAKE OFF**. Нужен свободный слот в MAIN и запас по весу.

Пока броня надета, она:
- видна всем игрокам как жилет на торсе;
- учитывается в весе MAIN (3–7 кг в зависимости от варианта);
- показывает остаток очков в карточке предмета и в стандартной полосе
  брони SA-MP;
- **не лежит на земле** и не может быть подобрана другим игроком.

## Урон

При попадании броня принимает на себя `ABSORB`% урона и тратит свои очки.
Очки кончились — жилет **уничтожается** (предмет удаляется, игроку пишется
сообщение). Пока игрок лежит раненым (`downed`), броня не защищает.

## Своя текстура

Текстура лежит **только у клиента** в `arm/`, сервер лишь называет её.
Как добавить запись и что делать, если объект белый — в
[клиентские текстуры](КЛИЕНТСКИЕ_ТЕКСТУРЫ.md). Коротко:

| id | Что | Форма | TXD в `arm/` | Текстура |
|---|---|---|---|---|
| 0 | BODY ARMOUR | 1242 | war1 | armour |
| 1 | VEST | 1242 | war1 | vest2 |
| 2 | свободный слот | 1242 | — | — |

Боевые свойства каждого id (очки, процент поглощения, вес) — в
`armour.inc`, форма и текстура — в `skins.inc`.

## Посадка жилета по скину

`/armfit` — админ 1+ с надетой бронёй: открывает редактор (как `/bagfit`
для рюкзака), сохраняет смещение для текущего скина в таблицу `armour_fit`.
Отмена оставляет прежнюю посадку.

По умолчанию жилет висит на кости «spine» со смещением `y = 0.06`.

## Проверка

```
/setadmin <ваш id> 1
/giveitem <ваш id> armour 0
/inv            # выбрать броник -> WEAR
/armfit         # при необходимости подогнать под скин
```

Ограничения: внешний вид жилета определяет **клиент** — файл должен лежать у
него в `arm/` и читаться mod loader'ом. Настоящие кастомные `.dff`/`.txd`,
которые сервер сам раздаёт игрокам, — это SA-MP 0.3.DL
(`AddCharModel`, `AddSimpleModel`); в 0.3.7 такой возможности нет.
