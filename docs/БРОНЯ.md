# Бронежилет

Броня — **отдельный предмет инвентаря** (тип 7). Пока она надета, жилет
отрисовывается на игроке и гасит часть урона. Реализация:
`server/pawno/include/railway/armour.inc`.

## Как надеть

1. Получить предмет: `/giveitem <id> armour [1-3]` (админ 1+).
   `1` — лёгкий (50 очков, 50%), `2` — обычный (100 очков, 65%),
   `3` — тяжёлый (150 очков, 80%). По умолчанию — `2`.
2. Открыть `/inv`, выбрать броник в MAIN, нажать **WEAR**.
   Предмет уходит из сетки в слот брони (ячейка CHARACTER, третья сверху —
   рядом с рюкзаком и активным оружием).
3. Снять: выбрать надетую броню (клик по ячейке брони или по слоту) и нажать
   **TAKE OFF**. Нужен свободный слот в MAIN и запас по весу.

Пока броня надета, она:
- видна всем игрокам как жилет на торсе;
- учитывается в весе MAIN (3–7 кг в зависимости от варианта);
- показывает остаток очков в карточке предмета и в стандартной полосе
  брони SA-MP;
- **не лежит на земле** и не может быть подобрана другим игроком.

## Урон

При попадании броня принимает на себя `ABSORB`% урона и тратит свои очки.
Очки кончились — жилет **уничтожается** (предмет удаляется, игроку пишется
сообщение). Пока игрок лежит раненым (`downed`), броня не защищает.

## Своя текстура — как подключить

**SA-MP 0.3.7 не умеет отправлять файлы клиенту.** Поэтому сама текстура
должна уже лежать в игре у игрока: через **Mod Loader** (папка в корне игры,
например `modloader/arm/war1.txd`) или заменой TXD внутри `gta3.img`.
Сервер при этом решает только то, **какую модель** показать. Всё настраивается
в начале `server/pawno/include/railway/armour.inc`.

### Вариант 1 (самый простой): ваша текстура заменяет родной TXD модели

Если вы положили `war1.txd`, который перекрывает текстуру **самой модели
жилета**, достаточно указать модель — клиент нарисует вашу текстуру сам:

```pawn
stock RW_ArmourModel(variant)
{
    switch (variant) {
        case 1: return 1242;      // <- id вашей модели (по умолчанию броник GTA SA)
        ...
```

`RW_ArmourTxd` и `RW_ArmourTexture` при этом **оставляем пустыми** (`""`).

### Вариант 2: текстура лежит отдельным TXD

Если нужен TXD, который модель сама не использует, заполните обе функции
(имя TXD **без расширения** и имя текстуры внутри него):

```pawn
stock RW_ArmourTxd(variant, dest[], size = sizeof dest)
{
    switch (variant) {
        case 2: format(dest, size, "war1");    // war1.txd
        ...
stock RW_ArmourTexture(variant, dest[], size = sizeof dest)
{
    switch (variant) {
        case 2: format(dest, size, "armour");  // текстура внутри war1.txd
        ...
```

Тогда сервер создаёт жилет как объект и ставит на него материал
(`SetObjectMaterial` + `AttachObjectToPlayer`). TXD всё так же должен быть
в игре у клиента.

> Если объект после этого стал белым/серым — клиент не нашёл такую текстуру:
> проверьте имя TXD и имя текстуры внутри (без `.txd`, регистр не важен).

## Посадка жилета по скину

`/armfit` — админ 1+ с надетой бронёй: открывает редактор (как `/bagfit`
для рюкзака), сохраняет смещение для текущего скина в таблицу `armour_fit`.
Отмена оставляет прежнюю посадку.

По умолчанию жилет висит на кости «spine» со смещением `y = 0.06`.

## Проверка

```
/setadmin <ваш id> 1
/giveitem <ваш id> armour 2
/inv            # выбрать броник -> WEAR
/armfit         # при необходимости подогнать под скин
```

Ограничения: внешний вид жилета определяет **клиент**, сервер только выбирает
модель и материал. Настоящие кастомные `.dff`/`.txd`, которые сервер сам
раздаёт игрокам, — это SA-MP 0.3.DL (`AddCharModel`, `AddSimpleModel`); в 0.3.7
такой возможности нет.
