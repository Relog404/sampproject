# Клиентские текстуры одежды (папка `arm/`)

Все текстуры лежат **только у игрока** в папке игры `arm/`:

```
GTA San Andreas/
  arm/
    war1.txd
    vest.txd
    ...
```

Сервер не хранит и не отправляет ни одного файла: он лишь говорит
«на этом предмете — текстура *такая-то* из TXD *такого-то*», а клиент берёт
её из своей папки `arm/`. Всё, что делает сервер, — одна строчка на текстуру
в `server/pawno/include/railway/skins.inc`.

## Как это работает

1. Игрок кладёт `.txd` в `arm/` — например файл `arm/war1.txd`, значит имя
   TXD — **`war1`** (без расширения). Его **mod loader** подхватывает файл при
   запуске игры. Сам GTA папки в корне не читает — нужен mod loader
   (или тот же TXD, вшитый в `gta3.img`).
2. В `skins.inc` для этой текстуры заведена запись: форма (модель), имя TXD
   **без расширения** и имя текстуры внутри него.
3. Когда предмет надет, лежит на земле или лежит в мире, сервер создаёт
   объект этой формы и ставит на него материал:
   `SetObjectMaterial(object, 0, model, "war1", "armour", 0)`.
   Клиент находит TXD `war1` у себя (из `arm/`) и рисует его текстуру.

Данные предмета (`data`) хранят **id записи** из `skins.inc`.

## Как добавить свою текстуру

1. Положить файл в `arm/` на клиенте.
2. Добавить по одной строке в три switch'а в начале `skins.inc`:

```pawn
stock RW_SkinModel(id)          // форма (какую модель нарисовать)
{
    switch (id) {
        case 0: return 1242;    // 0 - броник
        case 1: return 1242;    // 1 - ваш новый жилет
        case 2: return 1242;    // 2 - свободный слот
    }
    return 1242;
}
stock RW_SkinTxd(id, dest[], size = sizeof dest)      // имя TXD без ".txd"
{
    switch (id) {
        case 0: format(dest, size, "war1");
        case 1: format(dest, size, "mytxd");    // arm/mytxd.txd
        case 2: format(dest, size, "");
    }
    return 1;
}
stock RW_SkinTexture(id, dest[], size = sizeof dest)  // имя текстуры внутри
{
    switch (id) {
        case 0: format(dest, size, "armour");
        case 1: format(dest, size, "mytexture");
        case 2: format(dest, size, "");
    }
    return 1;
}
```

3. Увеличить `RW_SkinCount()` на число записей (сейчас `3`, максимум `16`).
4. Перекомпилировать `railway.pwn` — и всё.

**Без перекомпиляции** — командой в игре (админ 1+), имена сохраняются в БД
и сразу применяются к надетым и лежащим предметам:

```
/skin                          # показать все записи
/skin 0 war1 armour            # id 0 -> arm/war1.txd, текстура "armour"
/skin 1 war1 vest2             # id 1 -> тот же TXD, другая текстура
```

Запись из БД важнее скомпилированной: если вы поменяли имя командой, правка
`skins.inc` уже ни на что не влияет (пока строку не удалить).

Пустые TXD/текстура (`""`) означают: оставить родную текстуру модели —
удобно, когда ваш `.txd` просто перекрывает штатный.

## Где текстура видна

| Где | Показывается |
|---|---|
| Надетый жилет на игроке | да |
| Предмет, брошенный на землю | да |
| Предмет, восстановленный при старте сервера | да |
| Иконка предмета в `/inv` | **нет** — карточка предмета рисуется страницей, модель не показывается |

## Ликвидный или донатный

Тип предмета один и тот же (броня — тип 7), разница только в **id скина**,
поэтому ничего переделывать не нужно. За вид товара отвечает один switch
в `skins.inc`:

```pawn
stock bool:RW_SkinBound(id)
{
    switch (id) {
        case 0: return false;   // ликвидный: можно выбросить, продать, отдать
        case 1: return true;    // личный (донатный): не выкидывается и не передаётся
        case 2: return false;
    }
    return false;
}
```

| | Ликвидный (`false`) | Личный/донатный (`true`) |
|---|---|---|
| Выбросить на землю | можно | **нет**, кнопка DROP скрыта |
| Отдать другому игроку | можно (когда появится обмен) | нет, только админ через `/giveitem` |
| Потерять | можно | нельзя — остаётся на аккаунте |
| Карточка предмета | обычное описание | «bound to this account» |

Сейчас **всё ликвидно** (`false`) — поведение не меняется, пока вы не решите.
Скажите, какие id сделать донатными, и я переключу одной строкой.

## Если объект белый или серый

Клиент не нашёл такую текстуру. Проверьте по порядку:

1. Файл лежит именно в `arm/` **в папке игры** и mod loader его видит
   (в логе mod loader'а строка с именем TXD).
2. В `skins.inc` имя TXD без `.txd`, имя текстуры — как внутри файла
   (посмотреть можно в TXD Workshop / Magic.TXD).
3. Регистр не важен, опечатки — важны.
4. id предмета совпадает с номером case: `/giveitem <id> armour 1` — это
   запись `case 1`.

## Ограничения

- **SA-MP 0.3.7 не отдаёт файлы клиенту**, поэтому текстура должна быть у
  каждого игрока сама. Проверить со стороны сервера, есть ли файл, нельзя.
- Если файла нет, игрок увидит либо родную текстуру модели (если TXD не
  указан), либо белый объект (если указан).
- Автораздача арта игрокам — только SA-MP 0.3.DL (`AddCharModel`,
  `AddSimpleModel`).
