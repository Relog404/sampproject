# Railway — SA-MP, native TextDraw

Сервер SA-MP 0.3.7 для Windows. **Без CEF, браузеров, ASI и сторонних плагинов.**
Русские меню работают через штатные окна SA-MP, HUD и уведомления — PlayerTextDraw.
Дополнительный режим компактных кликабельных TextDraw включается командой `/uitd`.

## Что есть

- Русские окна входа/регистрации. Пароль вводится
  в стандартном **скрытом диалоге**, поскольку TextDraw не поддерживает безопасное
  текстовое поле. Существующему нику предлагается только вход, новому — регистрация с повтором пароля.
- Локальная SQLite `server/scriptfiles/railway.db`: соль + SHA-256 пароля,
  деньги, скин, права администратора. Существующая база совместима.
- `/spcar <400–611>` — личная машина. Ключ, двери и двигатель разделены.
  **Если ключ оставлен, любой водитель может завести машину.**
- Меню машины: двери, двигатель, ключ, фары, конкретные пассажиры.
  Снаружи выбирается машина под центром камеры до 6 м; внутри — текущая.
- `/settings`: русское окно настроек доступных игровых действий, на сессию.
- Цифровой TextDraw-спидометр: скорость, передача, ключ/мотор/двери, полоса RPM.
- Уведомления снизу с появлением/затуханием и убывающей полосой на 3 секунды.
- Метка на карте сохраняется и предлагает компактное русское подтверждение «Да / Нет».
  `/tpm` повторяет предложение телепорта, `/delmark` удаляет метку.

## Управление

| Действие | По умолчанию | Команда |
|---|---|---|
| Меню машины | **Y** | `/vmenu` |
| Двигатель | **N** | `/engine` |
| Двери | **H** | `/door` |
| Ключ | кнопка в меню | `/key` |
| Настройки | — | `/settings` |
| Закрыть панель | **Esc** / кнопка ZAKRYT | — |

В `/settings` доступны нативные действия **Y / N / H / LAlt**. Совпадающее
назначение меняется местами, поэтому три действия не конфликтуют.
**Это игровые действия SA-MP, не произвольные физические клавиши.** Без
клиентского плагина сервер не может ловить Ъ, `\` или L как Windows VK.
Старые CEF-бинды удалены. Настройки GTA могут изменить фактические кнопки.

### Исправление сломанных букв

По умолчанию **`/uiru`**: русский текст рисуется в штатных окнах SA-MP и
не зависит от `fonts.txd`. Вход, регистрация, машина, настройки, пассажиры и
подтверждение телепорта используют этот режим. Ничего менять в GTA не нужно.

**`/uitd`** включает прежние компактные кликабельные TextDraw, но с читаемой
транслитерацией. Спидометр и уведомления в обоих режимах — безопасные TextDraw:
сырые русские байты больше не передаются в игровой шрифт. Это устраняет
ошибку предыдущей версии, в которой русский был включён без проверки шрифта.
`/tdrus` — алиас `/uiru`, `/tdlatin` — алиас `/uitd`; они больше не включают
потенциально сломанную кириллицу. Данные аккаунтов и пароли не меняются.

Панели уменьшены: меню ТС 190×214, вход 220×184, подтверждение 200×124
в виртуальной сетке SA-MP 640×448. Единый стиль — графит, тёплый акцент,
тонкие строки и компактные кнопки; спидометр также стал меньше.

## Запуск

1. Смените `rcon_password` в `server/server.cfg`.
2. Запустите `server/samp-server.exe` из папки `server`.
3. Подключитесь обычным SA-MP 0.3.7 клиентом.

`plugins` в конфигурации пуст. CEF-ресурсы, cef.dll, cef.asi, браузерные порты и
клиентский установщик больше не нужны. Достаточно игрового UDP-порта 7777
(либо выбранного вами `port`). Не устанавливайте старые CEF-файлы из прежних версий.

Проверка комплекта: `powershell -ExecutionPolicy Bypass -File .\setup.ps1`.
Сборка штатным Windows-компилятором:

```powershell
powershell -ExecutionPolicy Bypass -File .\server\tools\build-gamemode.ps1
```

## Обновление с CEF

Остановить сервер, обновить `railway.amx` и `server.cfg`. Старые
`scriptfiles/cef/` и плагин `cef.dll` не используются и могут быть удалены.
Клиенту не нужно скачивать ничего. **Не удаляйте `scriptfiles/railway.db`!**
Прежние аккаунты, хеши паролей и административные права сохраняются.
Старый `cef.asi` клиент может убрать сам: для этого сервера он не нужен.

## Проверки

```sh
python3 -m unittest discover -s tests -p '*_test.py'
```

Проверяются SQLite, импорты собранного AMX (без CEF), конфигурация и контракты
TextDraw-экранов. Это не заменяет игровой тест на Windows.

## Инвентарь

`/inv` — TextDraw-инвентарь: **50 слотов / 50 кг**, с рюкзаком ещё
**30 слотов / 40 кг**; превью персонажа, 8 резервных слотов экипировки и
50 слотов предметов рядом. Рюкзак отображается на спине. Выброшенные предметы
видны в мире. Предметы: `1` — рюкзак, `2` — ключ машины (выдаётся при `/spcar`).

Админам: `/giveitem <playerid> 1` или `/giveitem <playerid> 2 <vehicleid>`.
Назначение админов — только консоль: `setadmin Nick_Name 1`.
