# Railway — «Железнодорожный вокзал»

Готовый сервер **SA-MP 0.3.7 (клиент R5-2)** для Windows с CEF-интерфейсом:
спавн на железнодорожном вокзале Los Santos, регистрация/вход через красивое
анимированное CEF-меню, персональные машины по `/spcar` с ключами и дверями,
и внешний CEF-спидометр с передачей внутри прибора.

```
server\   — всё, что запускается на сервере (samp-server.exe, гейммод, CEF-ресурсы)
client\   — то, что нужно положить в папку GTA San Andreas (cef.asi + папка cef\)
docs\     — подробные инструкции
setup.ps1 — установка CEF-компонентов одной командой
```

---

## Что уже работает

| Возможность | Детали |
|---|---|
| Спавн на вокзале | Los Santos, Unity Station — камера облетает перрон, пока игрок входит в аккаунт |
| Регистрация и вход | CEF-модалка: стеклянная карточка, анимации, табы, индикатор надёжности пароля, тосты об ошибках |
| Пароли | `SHA256_PassHash(пароль, соль)`, соль уникальна для каждого аккаунта, открытый текст не хранится и не пишется в лог |
| База | SQLite, встроенная в `samp-server.exe` (`scriptfiles\railway.db`) — сторонние плагины БД не нужны |
| `/spcar <id>` | Спавнит стандартную модель SA-MP (400–611) рядом с игроком, **владелец — тот, кто вызвал команду** (в том числе админ) |
| Ключи и двери | Поехать может только владелец, у которого вставлен ключ; при открытой двери без ключа можно сесть, но не поехать |
| Спидометр | Внешний CEF-HUD появляется при посадке за руль: скорость, дуга шкалы, **передача внутри прибора**, индикаторы ключа/двигателя/дверей |

## Быстрый старт (Windows)

1. **Поставьте клиент SA-MP 0.3.7 R5-2** (с сайта `sa-mp.mp`) в папку с GTA San Andreas.

2. **Установите CEF-компоненты** — откройте PowerShell в папке проекта:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\setup.ps1 -GtaPath "C:\Program Files (x86)\Rockstar Games\GTA San Andreas"
   ```

   Скрипт скачает официальные файлы `aurora-mp/omp-cef` v1.4.0, проверит SHA-256,
   положит `server\plugins\cef.dll`, `server\pawno\include\cef.inc`,
   а в папку игры — `cef.asi` и папку `cef\`.
   Если папку игры не указать, файлы останутся в `client\gta-files` — их нужно
   скопировать в корень GTA вручную.

3. **Смените `rcon_password`** в `server\server.cfg`.

4. **Запустите `server\samp-server.exe`** и подключайтесь на `127.0.0.1:7777`.

> Без `cef.dll` гейммод не загрузится: он использует нативы CEF, а SA-MP не
> грузит скрипт с неизвестными нативами (`Run time error 19`). Сначала шаг 2,
> потом запуск.

Если сервер в интернете — откройте **UDP 7777** (игровой) и **UDP 7779**
(CEF-канал: `port + 2`).

## Правила машин

| Ситуация | Сесть | Поехать |
|---|---|---|
| Двери закрыты | ❌ нельзя | ❌ |
| Двери открыты, ключа нет | ✅ можно (пассажиром или за руль) | ❌ двигатель не заводится |
| Двери открыты, ключ вставлен, **вы владелец** | ✅ | ✅ |
| Двери открыты, ключ вставлен, но машина чужая | ✅ | ❌ двигатель заблокирован |

Рабочий цикл владельца:

```
/spcar 411       — машина создана (двери закрыты, ключа нет)
/door            — открыть двери
(сесть за руль)
/key             — вставить ключ: двигатель заводится, двери закрываются
```

Сервер проверяет право на движение каждые 0.4 с: если за рулём не владелец или
ключа нет — двигатель глушится, скорость обнуляется, игрок получает объяснение.
Проверка идёт на сервере, клиентскими правками её не обойти.

## CEF-интерфейс

**Экран входа** (`server\scriptfiles\cef\railway_auth\`)

* стеклянная карточка с мягкой тенью и подсветкой, фон затемняется и размывается
  (`backdrop-filter`) поверх игры;
* появление карточки, каскадное появление полей, отрисовка логотипа, скользящий
  переключатель «Вход / Регистрация»;
* поля с фокус-подсветкой, кнопка «глаз», индикатор надёжности пароля;
* состояния кнопки: обычное / загрузка (спиннер) / успех (галочка);
* ошибки: тост сверху + красная рамка поля + короткий «шейк» карточки;
* ник игрока подтягивается с сервера, вкладка выбирается автоматически
  (есть аккаунт → «Вход», нет → «Регистрация»).

**Спидометр** (`server\scriptfiles\cef\railway_speedo\`)

* круглый прибор в правом нижнем углу, дуга скорости с градиентом и красной зоной;
* цифровая скорость, плавная стрелка (интерполяция на клиенте, сервер шлёт данные
  6–7 раз в секунду, картинка остаётся плавной);
* **передача внутри прибора** — `N`, `R`, `1…6`, со «прыжком» при переключении;
* индикаторы: ключ, двигатель, двери; при отсутствии прав — красная плашка
  «двигатель заблокирован» и красная шкала.

Обе страницы — чистые HTML/CSS/JS без внешних библиотек, шрифтов и CDN:
интернет на клиенте не нужен, ресурсы приходят с сервера (`http://cef/<resource>/…`).

Превью в браузере (без игры): откройте страницы напрямую — в них встроен
демо-режим, который имитирует события сервера.

## Совместимость и честные оговорки

* **Сервер:** официальный Windows-пакет SA-MP **0.3.7-R2-2-1** (последний
  серверный релиз ветки 0.3.7) — он штатно работает с клиентом 0.3.7 R5-2.
* **Плагин CEF:** `aurora-mp/omp-cef` **v1.4.0** (14.10.2026, CEF 148).
  В документации плагина заявлены клиенты R1, R3-1, **R5-1** и 0.3.DL-R1;
  про R5-2 отдельных заявлений нет.
* **Почему R5-2 всё же работает:** патч-релиз R5-2 не менял `samp.dll` — это
  тот же самый файл, что в R5-1 (`TimeDateStamp = 0x6372C39E`,
  `SizeOfImage = 0x27E000`; так указано и в обсуждении самой библиотеки, PR #55
  репозитория `aurora-mp/omp-cef`). Плагин сначала определяет билд по PE-подписи
  и опознаёт R5-2 как **R5**, то есть берёт адреса R5-1 — они совпадают.
  Если подпись незнакомая (например, файл перепакован аддоном), включается
  проверка версии файла: у R5-2 это `0.3.7.5`, что снова даёт ветку **R5**.
  Свой билд можно проверить скриптом `client\check-samp-build.ps1` — он покажет
  подпись, версию и вердикт.
* Если на каком-то конкретном билде samp.dll интерфейс не появится, поставьте
  клиент **0.3.7 R5-1** — он поддержан официально. Сервер менять не нужно.

## Требования

* Windows 7 SP1 / 8 / 10 / 11 (x86-совместимые библиотеки: сервер и клиент 32-битные).
* GTA San Andreas 1.0 US + SA-MP 0.3.7 R5-2.
* ASI loader в папке игры (`dinput8.dll` от Silent's ASI Loader или аналогичный) —
  без него `cef.asi` не загрузится. Скрипт проверки об этом предупредит.
* Интернет — только на этапе `setup.ps1`. Игре и серверу после установки внешняя
  сеть не нужна.

## Частые проблемы

| Симптом | Причина / решение |
|---|---|
| В логе `Failed (plugins/cef.dll)` | не выполнен `setup.ps1` либо файл заблокирован антивирусом |
| `Script[gamemodes/railway.amx]: Run time error 19` | нет `plugins\cef.dll` (нативы CEF не зарегистрированы) |
| CEF-меню не появляется, в чате «Клиент CEF не найден» | в GTA нет `cef.asi` / папки `cef\` / ASI loader |
| Меню появляется, но пустое | ресурсы не отдаются: проверьте `scriptfiles\cef\railway_auth\` и `cef_resources_loader_mode cef` |
| Открывается только текст-диалог входа | это резервный режим (CEF не поднялся за 12 с) — смотрите пункт выше |
| Не подключается, «Retrieving info…» | порт/UDP 7777, брандмауэр, `lanmode`/`bind` |
| Спидометр не обновляется | заблокирован UDP 7779 (`port + 2`) |

## Сборка гейммода

`railway.amx` уже собран и лежит рядом с исходником. Пересобрать:

```powershell
powershell -ExecutionPolicy Bypass -File .\server\tools\build-gamemode.ps1
```

или вручную:

```
server\pawno\pawncc.exe server\gamemodes\railway.pwn -i server\pawno\include -o railway.amx -d3
```

Исходники `.pwn/.inc` — в **Windows-1251** (стандарт Pawno, так русский текст
корректно отображается в чате и диалогах SA-MP). HTML/CSS/JS — в UTF-8.

При сборке **не используйте `-O2`**: оптимизатор включает «макро-опкоды» и пишет
AMX версии 9, который сервер SA-MP 0.3.7 не грузит. `-O0`/без оптимизации даёт
совместимую версию 8 — именно так собран приложенный `railway.amx`.

## Как это проверялось

* **Логика гейммода** прогнана на виртуальной машине Pawn (Pawn 3.10.10,
  рантайм `amx.c`) с заглушками нативов SA-MP и SQLite: 22 из 22 сценариев
  PASS — загрузка гейммода, подключение, `auth:ready`, регистрация, повторная
  регистрация того же ника, неверный пароль, повторный вход, вход после
  переподключения, выдача стартовых денег на спавне, `/spcar 411` (успех),
  `/spcar 999` и `/spcar 449` (отказы), посадка без ключа, `/key`, чужое авто,
  закрытые двери, выход из машины, тик спидометра, завершение гейммода.
* **Совместимость AMX с 0.3.7**: в собранном `railway.amx` заголовок
  `file_version = 8`, `amx_version = 8`, а в листинге ассемблера нет ни одного
  опкода из новых версий (`push2…push5`, `load.both`, `symtag`, `sysreq.d/nd`) —
  только классический набор AMX v8.
* **`cef.inc`** в `server\pawno\include` побайтово совпадает с `v1.4.0`
  (SHA-256 `a8950e32…8015`), поэтому после `setup.ps1` пересборка ничего не ломает.
* **CEF-страницы**: все `getElementById` ссылаются на существующие элементы,
  все `@keyframes` и CSS-переменные определены, внешних запросов (CDN, шрифты)
  нет — интерфейс полностью офлайновый.
